Request–response

The browser sends an HTTP request. Flask validates the session, checks authorization, performs the requested operation, and returns an HTTP response.

File transfer

Uploads travel from the client to Flask using multipart/form-data. Downloads are served only after ownership or share-token checks.

TCP/IP

HTTP communication is carried over TCP/IP. This page shows application events and does not claim to inspect packet-level traffic.

SHA-256 integrity

Each uploaded file gets a SHA-256 digest. The server recomputes it before a download and refuses content that does not match.
